# Forever Unlocks

**Forever Unlocks** is a lightweight, modular World of Warcraft addon that gives you a complete overview of upcoming class abilities, race-specific mounts, and profession milestones — complete with one-click map pins and automatic trainer scanning.

---

## ✨ Features

- **All 9 Playable Classes:** Pre-configured level milestones, class quest reminders, and talent unlocks for Warrior, Paladin, Hunter, Rogue, Priest, Shaman, Mage, Warlock, and Druid.
- **Race-Specific Mount & Riding Trainers:** Automatically detects your character's race (`UnitRace`) to display the exact Level 40 (60%) and Level 60 (100%) mounts, gold costs, and Riding Trainer locations.
- **Complete Profession Tracking:** Covers all primary and secondary professions (*Blacksmithing, Mining, Alchemy, Herbalism, Engineering, Leatherworking, Skinning, Tailoring, Enchanting, First Aid, Cooking, Fishing*) with rank caps, costs, and trainer/vendor locations.
- **Live Trainer Auto-Scanner:** Talking to any Class or Profession Trainer automatically scans and saves every available and future spell/recipe, rank requirement, and gold cost across your account.
- **One-Click Map Pins:** Set super-tracked map waypoints directly to trainers and vendors with a single click.
- **Blizzard-Style UI & Filters:** Built with `PortraitFrameTemplate`, featuring dynamic class/profession portraits, class-colored headers, visual progress bars, a live search bar, and a **"Hide Unlocked"** toggle.
- **Minimap Button:** Left-click to open/close `/unlocks`, or right-click for a quick-navigation menu and waypoint reset.

---

## 🚀 Usage

- **`/unlocks`** — Opens or closes the main Forever Unlocks window.
- **Minimap Icon:**
  - **Left-Click:** Toggle the main window.
  - **Right-Click:** Open the quick-navigation menu or clear your active map pin.
  - **Drag:** Move the icon around the minimap.
- **Auto-Scanning:** Simply open a Class or Profession Trainer dialog in-game. Scanned recipes and spell ranks are automatically merged into the UI and saved permanently when you `/reload` or log out.

---

## 📦 Installation

1. Download the latest release or clone this repository.
2. Place the `ForeverUnlocks` folder inside your World of Warcraft `_classic_era_\Interface\AddOns\` directory.
3. Restart the game or type `/reload` in chat.
